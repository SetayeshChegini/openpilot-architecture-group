Semester deliverable

Architecture Report

Group H is proposing a high-level conceptual architecture for OpenPilot's advertised functions using EECS 4314 course concepts. The design covers subsystems, interactions, data and control flow, concurrency, interfaces, use cases, dependencies, decisions, and trade-offs without claiming to document OpenPilot's real implementation.
