Assignment criteria

Assignment 1 Report Requirements

  • Final report length: 10–15 pages.
  • Format: Single-spaced, 12-point font.
  • Focus on conceptual architecture, not implementation details.
  • Include at least two sequence diagrams or state diagrams.
  • Include an architecture overview diagram.
  • Include a dependency diagram.
  • Explain the main subsystems and their interactions.
  • Describe control flow, data flow, and concurrency.
  • Explain how responsibilities are divided among participating developers.
  • Provide proper references and relevant external links.
  • Publish the final report on the Group H website.
  • Submit presentation slides in PDF format before the class presentation.
